Cómo se guarda

Tus decisiones se guardan en este navegador. Cuando termines (o cuando quieras) pulsa Descargar decisiones.json, súbelo a tu repositorio de GitHub en revision/decisiones.json (sustituyendo el anterior) y lanza el flujo «Actualizar». Los elementos ya decididos desaparecen solos; si los datos cambian, vuelven a salir.

«Aceptar todo lo visible» marca como correcto (sin cambiar nada) los elementos con opción «Correcto», «Visto» o «Son distintos» según el filtro activo; úsalo con un filtro de tipo.
