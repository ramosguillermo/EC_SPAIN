# Actualización automática y revisión

1. Sube esta carpeta a tu repositorio EC_SPAIN (GitHub Desktop o git). No se suben los datos descargados (.gitignore).
2. En GitHub: Settings > Pages > Source = **GitHub Actions**. Borra el workflow antiguo de Pages.
3. Pestaña Actions > «Actualizar datos y publicar» > Run workflow. La primera vez tarda 30-40 min; después se ejecuta cada lunes.
4. Revisión: abre https://ramosguillermo.github.io/EC_SPAIN/revision/ , decide, pulsa «Descargar decisiones.json» y súbelo a `revision/decisiones.json` del repositorio. El flujo lo aplica solo.
